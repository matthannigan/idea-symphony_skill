# Document Templates

Templates for the intermediate and final documents created during an Idea Symphony session. Each template lives in its own file in [templates/](templates/).

## Session files (root of session directory)

- [REQUEST.md](templates/request.md) — Original brainstorming request summary
- [USER-QUESTIONS.md](templates/user-questions.md) *(optional)* — User-provided questions to preserve through the workflow
- [PLAN.md](templates/plan.md) — Session configuration, Phase 2 roster plan, and per-phase status
- [BRAINSTORM.md](templates/brainstorm.md) — Final output document

## Synthesis files (per topic cluster)

- [synthesis-attributed.md](templates/synthesis-attributed.md) — Full synthesis with persona attribution (`medium`/`high`)
- [synthesis-merged.md](templates/synthesis-merged.md) — Synthesized points without attribution (`medium`/`high`)
- [synthesis-summary.md](templates/synthesis-summary.md) — Executive summary (all effort levels; see file for variants)
