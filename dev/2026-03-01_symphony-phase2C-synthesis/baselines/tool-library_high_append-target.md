## Integration Notes (per D1 tagging rules)

Each appended question carries a `[Persona · Internal-Cluster]` tag in the Phase 2C output. The cluster name need not be standardized across personas (each persona has its own cluster vocabulary). The persona name is mandatory; the internal-cluster tag is recommended for downstream Phase 3 routing.

**Placement in Phase 2C output:** All 48 appended questions appear in their own section after the Synthesize-group output, organized by persona (preserving the round-robin order within each persona). They are *not* interleaved with the synthesized cluster output — Append voices are kept visually distinct to preserve their disruptive value.

**Cross-cluster overlap with Synthesize universe:** Several Append questions overlap thematically with Synthesize clusters (and were noted in B1 / B2):

- **Constraint Flipper Q4** (liability as community-education gateway) overlaps Cluster 4 / CG-9. Per D1, not removed — the *inversion framing* is the value add.
- **Constraint Flipper Q5** (non-24/7 access as accountability engine) overlaps Cluster 1 (access friction). Inversion framing preserved.
- **Constraint Flipper Q7** (volunteer dependence as sustainability engine) overlaps Cluster 3 / CG-4. Inversion framing preserved.
- **Constraint Flipper Q6** (renter-homeowner diversity) overlaps Cluster 5 / CG-12 (founding-volunteer bias). Inversion framing preserved.
- **Politician Q3** (homeowner vs renter governance) overlaps Cluster 5 / CG-12 and Cluster 9. Political-analytical vocabulary preserved.
- **Politician Q8** (access vs risk political tension) overlaps Cluster 4 / CG-10 (preserve-distinct). Political framing of same tension preserved as distinct voice.
- **Politician Q10** (high-profile failure response) overlaps Cluster 4 / CG-9 (liability architecture). Political/crisis-response voice preserved.
- **Storyteller Q6** (when things go wrong — chapter of trust vs bureaucracy) overlaps Cluster 4 emotional framing (AA Q6). Narrative framing preserved as distinct voice.
- **Visionary Q4** (self-liquidating library) overlaps Cluster 11 FPT Q6 (means vs ends) — but in a paradigm-shifting rather than first-principles mode. Preserved.

Per D1, these overlaps are **not resolved by dropping the Append question** — each Append persona's distinctive framing is the contribution. A variant that drops CF Q4/Q5/Q7 because they "duplicate" synthesis content is failing SQ4.

## Cell-Specific Append Notes

1. **Politician is the high-risk Append persona for this cell.** Tool-library has stakeholder complexity (landlord, board, homeowners, renters, city hall, hardware stores, volunteers) but Politician at Tier 3 Append is less obviously an automatic include than Storyteller/Visionary/Analogist. SP1 variants that route Politician questions through synthesis rather than append will strip the political-analytical vocabulary that *is* Politician's contribution.

2. **CF Q4 overlap is instructive.** CF Q4 inverts "liability concerns as gateway to community education" — the *same topic* as CG-9 (liability architecture) but with the inverted framing that liability management *becomes* community-building programming. Synthesis cannot produce this inversion; only Append preserves it.

3. **Visionary Q4 (self-liquidating library) overlaps FPT Q6 but is not redundant.** FPT Q6 asks "are we confusing means with ends" — an analytical-reductive question. Visionary Q4 asks "design to put itself out of business within 5-10 years" — an aspirational reimagining. Both should appear: FPT Q6 in Cluster 11 (Synthesize), Visionary Q4 in Append. SP1 should check this distinction.

4. **Analogist's C2 "institutional/historical" cluster is unusually strong** for this topic — tool cooperatives, guilds, library book circulation, and seed libraries are all direct-analogue institutions, not metaphorical ones. This is the least "Analogist-ish" Analogist cluster — closer to institutional-design research than metaphor. SP1 may find Analogist's institutional questions convergent with ecosystem (Cluster 10) or alternatives (Cluster 11) content; keep appended per D1.

5. **Storyteller Q8 (negative narrative patterns)** is a meta-narrative question about what *not* to let happen. SP1 variants may miscategorize this as a risk-assessment question (Cluster 4) and merge it into liability clusters — that would strip its narrative-pattern framing. Keep appended.
