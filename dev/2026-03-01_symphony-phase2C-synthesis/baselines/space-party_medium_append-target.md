# space-party — medium — Append Target

**Append personas:** Provocateur (8), Analogist (8), Visionary (7), Storyteller (8)
**Append questions available (A_available):** 31 total across 4 personas
**Append quota per D1 (A_quota):** 5 per persona × 4 personas = **20 total**
**Expected selection:** 5 per persona via round-robin over each persona's internal clusters; when quota (5) exceeds internal cluster count (3), fill second round from largest cluster(s).

**D1 rule verbatim (medium effort):** "5 of 5-8 — One per cluster, then fill from largest clusters."

**Note:** Round-robin runs over *each persona's own internal clusters* (3–4 clusters per Perspective persona per D1 and R7), not over the B1 thematic clusters. The B1 thematic clusters serve as integration context for tagging (see Integration Notes below), but selection is internal-cluster-driven.

## Integration Notes

Per D1's implementation description in the persona-selection-guide: "Append selected questions to the Phase 2C output under a persona-labeled section." The final Phase 2C output structure should be:

1. **Synthesized clusters** (27 questions across 10 clusters, per B3 Target) — each cluster labeled with its theme.
2. **Append section** (20 questions) — tagged by persona, in a distinct section of the output (or interleaved with clusters if the synthesis prompt design elects interleaving).

**Tagging style:** Each Append question should carry the `[Perspective: persona-name]` tag so the reader can distinguish Append-group distinctive voice from synthesized Q&A. D1 is silent on interleaved-vs-segregated presentation; the default assumed here is a **segregated Append section at the end** (per the persona-selection guide's "directly appended" language), with clear persona-labels. SP1 may test variants of this integration.

**Cross-cluster tagging (optional):** Append questions can be secondarily tagged with the B1 thematic cluster they most closely relate to (column 2 in the table above), so synthesized clusters have a "see also" pointer to relevant Append content. Example: Cluster 8 (Theme) has a "see also: Analogist Q1–Q4, Q7; Storyteller Q1, Q4, Q6; Visionary Q4" reference. This is a nice-to-have, not a D1 requirement.

**Provocateur treatment:** Provocateur questions inherently don't map cleanly to B1 thematic clusters (see B1 Orphan section). They are tagged as `[Perspective: Provocateur]` with no thematic-cluster cross-reference; the provocation itself is the payload. This is consistent with the guide's note that "Absurd inversion + 'real insight' format is the entire value. Synthesizing strips the provocation."

## Sanity Check / Anomaly Notes

- **No Connector in this cell** (per GT1 Rev 3, space-party uses default Analogist). If a later GT1 revision reconsiders space-party as a Connector topic, rerun Analogist's walkthrough with Connector's internal clusters.
- **Provocateur orphans tagged as "Orphan" in B1 column** — this is expected and documented in B1. Scoring should not penalize a Provocateur question for lacking B1-thematic attribution.
- **Cluster-count-vs-quota arithmetic**: each persona has 3 clusters and quota 5 → 2 "refill" rounds. The refill biases toward the largest cluster. This causes mild within-persona-cluster over-representation (Analogist's industry/institutional cluster ends up with 3 of 5 Analogist selections, 60%). This is D1-expected behavior and not a distortion to correct.
- **Storyteller Q2 (hero's journey) is dropped from Append but its concern survives** via Analogist Q4 (flight mission operations) which addresses the same underlying mission-framing concept from a different angle. This illustrates why D1's round-robin works at the persona level rather than the thematic level — the thematic redundancy is absorbed without requiring cross-persona coordination.
