## Integration Notes

Per D1's implementation description in the persona-selection-guide: "Append selected questions to the Phase 2C output under a persona-labeled section." The final Phase 2C output structure should be:

1. **Synthesized clusters** (38 questions across 11 clusters per B3 Target) — each cluster labeled with its theme.
2. **Append section** (37 questions) — tagged by persona, in a distinct section of the output (or interleaved with clusters if the synthesis prompt design elects interleaving).

**Tagging style:** Each Append question should carry the `[Perspective: persona-name]` tag so the reader can distinguish Append-group distinctive voice from synthesized Q&A. D1 is silent on interleaved-vs-segregated presentation; the default assumed here is a **segregated Append section at the end** (per the persona-selection guide's "directly appended" language), with clear persona-labels. SP1 may test variants of this integration.

**Cross-cluster tagging (optional):** Append questions can be secondarily tagged with the B1 thematic cluster they most closely relate to (column 2 in the table above), so synthesized clusters have a "see also" pointer to relevant Append content. Example: Cluster 8 (Theme) has a "see also: Analogist Q1–Q4, Q7, Q8; Storyteller Q1, Q2, Q4, Q5, Q6; Visionary Q4, Q5; CF Q1, Q4" reference. This is a nice-to-have, not a D1 requirement.

**Provocateur treatment:** Provocateur questions inherently don't map cleanly to B1 thematic clusters (see B1 Orphan section). They are tagged as `[Perspective: Provocateur]` with no thematic-cluster cross-reference; the provocation itself is the payload. This is consistent with the guide's note that "Absurd inversion + 'real insight' format is the entire value. Synthesizing strips the provocation."

**Constraint Flipper placement:** Constraint Flipper's inversions DO map to thematic clusters (unlike Provocateur's pure orphans) — each CF question inverts a real constraint that appears in a specific synthesized cluster. SP1 should test whether adding the CF question as a "constraint-inversion companion" next to its paired synthesized cluster (interleaved) produces better output than the segregated Append section. The cross-cluster tags in the table above support either presentation.

## Sanity Check / Anomaly Notes

- **Full round-robin trivial at high effort.** The walkthroughs above exhaust each persona's clusters and end with all questions selected. This is by D1 design — the round-robin mechanic is validated by its behavior at low and medium effort (where quota < available); at high effort it's an identity operation.

- **Provocateur cluster-size anomaly.** Provocateur produced 8 questions this run (vs. expected ~7 "natural set point"). The extra question sits in P-B (ethical/boundary probing) cluster (Q5 about 11 children who don't know each other). This is within normal Provocateur variance; not a shortfall or overshoot. GT1 watchlist status: NOT watchlisted.

- **Constraint Flipper cluster-distribution anomaly.** CF's 6 questions distribute lopsidedly: CF-A (1), CF-B (1), CF-C (4). This triggers 3 rounds of drawing only from CF-C in the round-robin, but because quota = available at high effort, all 6 survive. If CF were being round-robin'd at medium effort (quota 3-5), the lopsided distribution would matter more — the first 3 picks would be Q1 (CF-A), Q2 (CF-B), Q3 (CF-C), bypassing Q4/Q5/Q6 in CF-C. Note this for potential cross-topic generalization: CF's constraint inversions on theme-rich topics may cluster heavily in one category (operational/logistical here), while on more generative topics (wearable-device, mobile-app), CF might distribute more evenly.

- **Analogist A-A cluster heavy (4 of 8 questions).** The industry/institutional-operations cluster is the Analogist's strongest mode for this topic (museum, theme park, flight mission, restaurant kitchen). At high effort this is noise; at medium/low it would bias round-robin toward those imports. Documented for cross-effort observation.

- **Storyteller S-B and S-C tied at 3.** Tiebreak by source order → S-B first. Relevant only for medium/low effort round-robin; at high effort all questions survive.

- **Visionary V-A cluster dominant (3 of 7).** Structural reimagination is the Visionary's strongest mode on this topic, with V-B and V-C both at 2 each. At high effort all survive.

- **Cluster-count-vs-quota arithmetic at high effort:** each persona has 3 clusters but A_quota = A_available ≥ 6 — 2+ "refill" rounds per persona. Refills bias toward largest clusters. This causes within-persona-cluster over-representation (Analogist's industry-institutional cluster ends up with 4 of 8 selections, 50%). This is D1-expected behavior.

- **Storyteller Q2 (hero's journey) and Analogist Q4 (flight mission operations) address the same underlying concept** from two persona angles. Both survive at high effort (all Append questions included), so the thematic redundancy is intentionally retained as "two voices on the same concern." SP1 should not treat this as a dedupe target in the Append stream.

- **Storyteller Q8 (photographic evidence) is NOT merged into the Cluster 9 synthesis stream** (unlike medium effort where we considered it for merger with Analyst Q11). At high effort, Storyteller Q8 is appended in full AND Analyst Q11 appears in synthesized Cluster 9. This is intentional double-coverage — both voices on photo-documentation survive, one from the Storyteller's narrative register, one from the Analyst's measurement register.

- **No GT1 watchlist concerns.** TDA1 confirms space-party/high is not watchlisted; all 5 GT1-medium-confidence cells are in other topics/effort levels.
