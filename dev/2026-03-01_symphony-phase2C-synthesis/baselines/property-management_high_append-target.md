## Integration Notes

Per D1's implementation description in the persona-selection-guide: "Append selected questions to the Phase 2C output under a persona-labeled section." The final Phase 2C output structure should be:

1. **Synthesized clusters** (44 questions across 12 clusters per B3 Target) — each cluster labeled with its theme.
2. **Append section** (36 questions) — tagged by persona, in a distinct section of the output (or interleaved with clusters if the synthesis prompt design elects interleaving).

**Tagging style:** Each Append question should carry the `[Perspective: persona-name]` tag so the reader can distinguish Append-group distinctive voice from synthesized Q&A. D1 is silent on interleaved-vs-segregated presentation; the default assumed here is a **segregated Append section at the end** (per the persona-selection guide's "directly appended" language), with clear persona-labels. SP1 may test variants of this integration.

**Cross-cluster tagging (optional):** Append questions can be secondarily tagged with the B1 thematic cluster they most closely relate to (column 2 in the table above), so synthesized clusters have a "see also" pointer to relevant Append content. Example: Cluster 1 (Regulatory) has a "see also: Analogist Q2, Q3; Constraint Flipper Q1-Q3, Q6; Visionary Q5; Storyteller Q3" reference.

**Provocateur treatment:** Provocateur questions inherently don't map cleanly to B1 thematic clusters. They are tagged as `[Perspective: Provocateur]` with no thematic-cluster cross-reference; the provocation itself is the payload. This is consistent with the guide's note that "Absurd inversion + 'real insight' format is the entire value. Synthesizing strips the provocation."

**Constraint Flipper placement:** Constraint Flipper's inversions DO map to thematic clusters — each CF question inverts a real constraint that appears in a specific synthesized cluster. In this cell, CF-A questions (Q1, Q2, Q3, Q6) all map to Cluster 1 (Regulatory) with secondary links to Cluster 9 (Differentiation). This heavy clustering in Cluster 1 is distinctive of this topic — the regulatory constraints are *the* constraints being flipped. SP1 should test whether adding CF questions as "constraint-inversion companions" next to Cluster 1 produces better output than the segregated Append section for this cell specifically.

**Storyteller placement:** Storyteller's 7 questions span 5 B1 clusters (1 Regulatory, 5 Operational, 6 Owner Relationship, 7 Community, 8 Quality, 11 Growth). This wide distribution reflects the topic's narrative richness — emergencies, first-meetings, neighbor-arc, election-shift, Elena-scaling are all genuine narrative anchors. In the segregated-Append presentation, Storyteller appears as a coherent "narrative section." In the interleaved presentation, Storyteller questions scatter across 5-6 clusters, which may fragment the narrative voice.

**Visionary placement:** Visionary's 8 questions cluster heavily in Cluster 12 (Reimagination) with cross-bridges to Cluster 7 (Community Wellbeing) and Cluster 9 (Regulatory-friction-as-advantage). In segregated presentation, Visionary reads as a coherent "what if we reimagined this entire business?" section. In interleaved presentation, Visionary's thread is scattered but each question lands next to related Synthesize content.

**Analogist placement:** Analogist's 6 questions each land on specific operational/strategic challenges (30-min response, governance, regulatory, coalition, distributed ops, insurance). These map cleanly to individual Synthesized clusters. Interleaving Analogist by thematic cluster produces coherent "what if we analogized this problem to X" moments near each relevant Synthesized cluster.

**PC1 implication:** The property-management/high cell is a good case for testing interleaved vs. segregated integration because (a) Append stream is large (36, near-equal to Synthesized 44), (b) Append questions map to clusters with varying levels of fidelity (CF high → Cluster 1; Visionary high → Cluster 12; Storyteller wide; Provocateur orphan; Analogist clean), (c) the topic has high narrative richness (Storyteller) AND high reimagination richness (Visionary) AND high constraint-richness (CF) — three different Append-voice registers competing for reader attention.
