## Cluster 1: Core Value Identification, Feature Stickiness & Differentiator Discovery

**Description:** The "what is this app actually for" question — how to identify the 3-4 features that represent genuine core value versus the 11-12 that are decorative, distinguishing retention-driving features from on-ramps-to-nowhere, feature stickiness and dependency analysis, keystone features whose removal would cascade, the job-to-be-done the user hired the app to do, the category-positioning question (is this a fitness app at all?), the single-feature imagined end-state, and the differentiator question independent of current usage data. Where Analyst's feature-engagement-matrix and cohort-framework scaffolding meets Appreciative Inquirer's "one thing done exceptionally well" and peak-user-experience framing, Devil's Advocate's feature-popularity-vs-value and unified-core-value-assumption critiques, Questioner's core-value-in-practice / true-differentiator / job-to-be-done challenges, and Systems Thinker's central-value-vs-surrounding archetype.
**Question count:** 12
**Contributing personas:** Analyst (3: Q1, Q2, Q3), Appreciative Inquirer (2: Q2, Q7), Devil's Advocate (2: Q1, Q7), Questioner (4: Q1, Q2, Q3, Q10), Systems Thinker (1: Q1)
**Primary dimension:** Strategic
**Sample questions (up to 5):**
- [Analyst Q1] Feature Engagement Matrix Analysis — feature stickiness, dependency patterns, correlation with 30-day retention beyond raw usage counts.
- [AI Q7] The "One Thing" Evolution — if this app became known for doing one thing exceptionally well, what would that be and how would it shape every aspect?
- [Questioner Q1] What does "core value" actually mean — features most people use vs. features creating most passionate engagement (not the same thing)?
- [Questioner Q3] What job are users hiring us to do — have we asked users what problem they thought they were solving when they downloaded?
- [Systems Thinker Q1] Features central to value proposition vs. those that surround it — "Success to the Successful" reinforcing what; hidden 2-3-feature combinations invisible in per-feature usage data.

**Primary dimension:** Strategic (with strong Human-centered secondary)
**Sample questions (up to 5):**

- [AI Q9] Migration with Grace — honoring passionate niche-feature user-base commitment while simplifying; graceful transition turning churn into deeper engagement.
- [DA Q5] Cascading user loss from feature cuts — each cut trigger abandonment from its niche; compounding churn from simultaneous removal; contingency plans if simplification backfires.
