### Selection Rationale

**Connector/Analogist decision:** Analogist (default)
- Swap rationale: The tool library is a single-community initiative — one neighborhood nonprofit serving one ~2,000-household neighborhood from one 500 sq ft space. Multi-stakeholder participation within one community is not the same as reconciling distinct institutional systems that constrain each other, so the default Analogist is retained (matches the negative-swap example "single-community initiatives (tool library)").
- Effort-invariance check: This decision would be identical at medium effort — topic structure (single-community, single-institution) does not change with effort level.
